# v0.2 development roadmap

1. Validate survey-specific vaccination denominators, questionnaires, ascertainment and coverage against published reports; add explicit human-reviewed harmonization records and citations.
2. Complete external installations on Windows/macOS/Linux, the CI matrix and ten researcher beta evaluations; add two distinct scientific examples required by PRD.
3. Add batch query planning, research project inspection commands, configurable storage quotas and concurrency-aware caching while retaining immutable source snapshots.
4. Improve population/indicator discovery with a reviewed terminology map, separate equivalent-stratum analysis and survey-specific metadata coverage.
5. Prepare authorized local microdata support only with explicit user-supplied access and validated complex-survey methods; keep restricted data out of public exports.

WHO/World Bank context and further visualization can follow validation of the core lineage and harmonization workflow. Forecasting and causal modeling require separate scientific specifications and validation; neither is implied by descriptive DHS trends.
